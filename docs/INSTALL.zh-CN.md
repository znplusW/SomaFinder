# 安装与升级

[English](INSTALL.en.md) · [返回首页](../README.md)

**顺序：先部署 Soma 后端，再启动 Soma Finder。** 当前发布测试适配 **Soma 0.10.7 / Windows x64**。其他 Soma 版本尚未作为本版完整适配承诺。

## 1. 先部署 Soma 后端

1. 打开 [Soma 0.10.7 官方发布页](https://github.com/AwesomeDog/soma/releases/tag/v0.10.7)。
2. 下载 [`soma-windows-x64.exe`](https://github.com/AwesomeDog/soma/releases/download/v0.10.7/soma-windows-x64.exe)。
3. 将它放入固定、可写的位置，例如 `%USERPROFILE%\Apps\Soma\`，可重命名为 `soma.exe`。不要将临时下载位置作为长期程序位置。
4. 在 PowerShell 验证版本（按实际路径修改）：

```powershell
$somaExe = "$env:USERPROFILE\Apps\Soma\soma.exe"
& $somaExe --version
```

应输出包含 `soma 0.10.7` 的版本信息。它是命令行程序，双击后一闪而过不等于安装失败。

按 [Soma 0.10.7 官方快速入门](https://github.com/AwesomeDog/soma/tree/v0.10.7#quick-start) 准备所需模型和工具。Soma 在首次同步时会下载所需组件，因此首次使用需要联网，并预留模型、工具和索引占用的磁盘空间。已部署用户继续使用已有模型和索引，无需重复创建或清空。

仅完成 EXE 下载不表示语义索引已经完成。第一次同步和模型加载可能需要较长时间。

## 2. 下载 Soma Finder

1. 从 [Soma Finder Releases](https://github.com/znplusW/SomaFinder/releases/latest) 下载 `SomaFinder-0.6.8-win-x64.zip`。
2. **完整解压**到可写文件夹。不要在压缩软件内直接运行，也不要只复制一个 EXE。
3. 打开 `SomaFinder.exe`。程序自带 .NET 运行时，无需另装 .NET。

一级目录为主程序、使用说明和更新说明；其余组件、源码及文档归入子目录。`Components` 是运行所需目录，请保留。

## 3. 选择后端并添加目录

1. 首次启动会查找 Soma；未找到时提供下载链接和手动选择入口。
2. 如果发现多份后端，选择你刚部署的 **0.10.7**，核对完整路径。
3. 在“设置 → 索引范围”添加需要收录的根目录，按需配置包含／排除规则，保存设置。
4. Finder 自动整理内部工作区；已有索引可继续使用。目录树的搜索勾选不会删除索引。
5. 根据同步设置和当前策略开始索引，也可使用“手动更新索引”。先看到关键词结果、后完成语义索引是正常阶段；状态栏和设置显示索引进度。

默认启用“使用电池时不自动同步”“切换到电池时，也停止正在进行的自动同步”“降低索引任务优先级”和低内存暂缓策略。定时自动同步需要在设置中开启；暂停状态会阻止新索引启动。

“低内存且长时间空闲时，释放模型内存”默认关闭，可在“同步与资源”中选择。开启后，需同时满足可用物理内存低于 1 GiB 持续 2 分钟，以及 Soma 无任务并空闲至少 15 分钟；索引执行期间不回收。下一次需要语义模型时重新加载，会增加首次搜索的等待时间。

同页另有默认关闭的“索引确认暂停 1 分钟后，释放搜索不需要的模型”。它只回收索引专用的 VL/OCR 资源；恢复索引会取消待执行回收，后续索引按需加载。两个选项独立，升级保留已有选择。

## 4. 搜索

在左侧勾选目录，输入关键词或自然语言，选择模式后搜索。双击结果打开原文件。混合搜索会尽量保留先返回的关键词结果；语义结果需要相应模型和向量索引就绪。

建议先用少量文件确认流程，再扩展索引范围。不要通过“重建索引”解决普通首次部署或升级问题；该按钮是清除后重建所选范围的维护操作。

## 升级与数据位置

1. 从托盘退出旧版 Soma Finder。
2. 完整解压新版到新文件夹。
3. 将旧版的 `data` 文件夹复制到新版 `SomaFinder.exe` 旁，保留个人设置。
4. 打开新版并核对已选择的后端路径。

Finder 设置位于程序旁的 `data`。Soma 的配置、模型和索引仍由 Soma 管理；Finder 会通过官方 CLI/API 和配置文件管理索引范围，不改写后端源码。

为保持跨版本托盘身份，托盘组件会复制到 `%LOCALAPPDATA%\SomaFinder\TrayHost`。自包含 .NET 程序首次启动也可能释放本机库到用户临时缓存。因此“免安装”不代表仅在解压目录写入文件。

## 常见问题

| 现象 | 检查方式 |
|---|---|
| 没有找到 Soma | 先完成第 1 步；在设置里选择实际的 Soma EXE |
| 只有关键词结果 | 检查模型下载、向量索引进度及后端错误提示 |
| 没有开始自动索引 | 检查暂停、电池、内存策略及自动同步开关 |
| 文件无法打开 | 核对原文件是否被删除、移动或外接盘已离线 |
| 后端版本不同 | 建议使用本版测试适配的 0.10.7；不要同时运行多个访问同一索引的后端副本 |
