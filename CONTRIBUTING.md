# Contributing / 贡献

Bug reports, reproducible examples, documentation fixes, and feature discussions are welcome. Use synthetic data and describe the Finder/Soma versions and Windows version.

Code is published under GPLv3 with separate commercial licensing available. **Before accepting third-party code**, the maintainer needs an explicit contributor agreement granting the rights needed for both GPLv3 distribution and separate commercial licensing. Opening a pull request does not by itself grant those additional rights. Discuss this with the maintainer before submitting a substantial implementation; do not copy code with incompatible licenses.

欢迎问题报告、可复现样例、文档修正和功能讨论。请使用合成资料，列出 Finder、Soma 和 Windows 版本。
